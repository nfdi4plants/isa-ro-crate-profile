## ISA RO-Crate Profile

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.13748893.svg)](https://doi.org/10.5281/zenodo.13748893)

This repository contains an [RO-Crate](https://www.researchobject.org/ro-crate/) profile for describing experimental data in plant sciences that is annotated by metadata following the [ISA model](https://isa-specs.readthedocs.io/en/latest/isamodel.html).

For a detailed description of the profile, see the [latest version](profile/isa_ro_crate.md).

The pure mapping of ISA terms to schema.org/[bioschemas](https://bioschemas.org/) terms, see the [mapping file](profile/isa_ro_crate_mapping.md).

## Contributing to this repository

The default branch `release` of this repo is kept in sync with the latest release tag and the zenodo record. 

Therefore, all contributions to this repo must target the `dev` branch, which is representing the work in progress for the next versioned release.
